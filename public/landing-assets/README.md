# Landing Assets

Reusable, self-contained SVG assets for a premium dark-green food-themed hero section.

## Files

- `hero-dish.svg` - main plated dish illustration for hero media.
- `side-dish.svg` - smaller supporting dish for secondary composition.
- `bg-leaves.svg` - full-width dark green leaf background pattern.
- `fork.svg` - warm metallic utensil silhouette for accent placement.
- `logo-mark.svg` - abstract circular food mark with leaves and plate shapes.

## Usage Notes

- Use directly from `/landing-assets/<file>.svg` in image tags, CSS backgrounds, or framework image components.
- The SVGs contain no text, external assets, raster images, or scripts.
- Pair `bg-leaves.svg` behind `hero-dish.svg` for the strongest landing-page composition.
- The palette is built around deep greens with warm gold highlights, so it works best on dark hero sections with restrained typography.
